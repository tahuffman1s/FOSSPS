FOSSPS

FOSS Person Shooter

A free, open-source engine built for one thing: multiplayer first-person shooters that are fast to play and easy to make.

View on GitHub See the roadmap

What it is aiming for

Four goals, in priority order. When they conflict, the earlier one wins.

01

Easy

From install to a playable networked match in minutes, with error messages that tell you what to do next.

02

Fast

High, stable frame rates and low input latency on mid-range hardware. Dedicated servers that are cheap to run.

03

Focused

Only multiplayer shooters. No general-purpose engine features to learn around.

04

Modern

Vulkan 1.3 rendering, FSR 3.1 upscaling and first-class controller support.

Scripting that reads like the game

Game modes, weapons and rules are written in Luau, a small typed scripting language. The goal is that someone who has played shooters can read a script and guess what it does.

  • Save the file and the running game updates
  • Autocomplete and type checking in your editor
  • Sandboxed, so community servers and mods are safe to run
  • The server decides what happens; clients can't cheat by editing scripts
-- main.luau: a whole team deathmatch
game.mode {
  name = "Team Deathmatch",
  teams = { "Red", "Blue" },
  scoreToWin = 50,
}

game.onKill(function(killer, victim)
  killer.team:addScore(1)
  victim:respawnAfter(3)
end)

A design sketch of the target experience. The API does not exist yet and will change.

Planned, not promised

What the engine is being built toward. None of this ships today.

Rust core

Memory-safe engine and server code, built with one command.

Server-authoritative netcode

Client prediction, lag compensation and a headless dedicated server.

Controller parity

Every action bindable on a gamepad. Nothing keyboard-only.

Linux, Windows, macOS

AppImage and .exe builds, with macOS as a stretch goal.

Roadmap

Work is tracked in the open as GitHub milestones.

  1. M0
    FoundationsWindow, input, a Vulkan triangle, a running Luau script and a one-command template game.
  2. M1
    Playable offlineLevels, movement, weapons, HUD and audio.
  3. M2
    MultiplayerDedicated servers, prediction, lag compensation and a sample team deathmatch.
  4. M3
    Modern graphicsLighting, shadows, anti-aliasing, FSR 3.1 and performance budgets.
  5. M4
    ShipPackaged builds for each platform, releases and a ten-minute tutorial.
