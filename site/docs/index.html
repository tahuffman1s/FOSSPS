Docs

FOSSPS is early, so these pages only describe what runs today. New here? Start with the tutorial.

Your first matchMake a game, change it while it runs, turn it into a team deathmatch and join it over the network. About ten minutes.

Install

There are no downloads yet: FOSSPS is built from its source code, which takes one command once Rust is installed. Step 1 of the tutorial walks through it.

cargo install --git https://github.com/tahuffman1s/FOSSPS fossps

Run the same line again to update. It needs Linux or Windows and a graphics driver with Vulkan 1.3; macOS is not ready.

Commands

Each one explains itself with --help, as in fossps run --help. A command that takes a game uses the folder you are in unless you name another.

CommandWhat it does
fossps new my-gameCreates a game that is ready to play, in a new folder called my-game, with a small level in it.
fossps runPlays the game in its level, the level.glb in the game's folder (a glTF Binary file, which Blender exports). It loads the script again every time you save it.
fossps run --openPlays the game and lets others on your network join it, with no separate server.
fossps editOpens the game's level to fly around, over a grid with lines a metre apart. Hold the right mouse button to look; W A S D fly, or use a gamepad's sticks. A list on the left names everything in the level: click a name to see where it is and how big it is, double-click to fly to it. Nothing can be changed there yet.
fossps checkTests the game without opening a window: runs a second of it and a pretend match, loads its level, and fails if the script has a mistake or the level cannot be read.
fossps serveRuns the game as a server, with no window, until Ctrl+C. --port picks another port than UDP 24680.
fossps joinFinds a game on your network and joins it. Give an address to join one elsewhere: fossps join 192.168.1.20.
fossps serversLists the games being served on your network.
fossps packageOn Linux, writes a download of the game to its dist folder, which players unpack and run without installing FOSSPS.
fossps controlsShows which key and button does what, and where the text file is that changes it. It makes the file if there is none; games read it when they start.
fossps demoOpens a test window that shows what your keyboard, mouse or gamepad is doing.
fossps benchMeasures how fast this computer draws a built-in test scene.

Scripting

A game is a folder with a main.luau in it, where the game starts, written in Luau. Everything the engine offers a script is in one table called game.

In a scriptWhat it is for
game.mode { … }Sets up the match: teams, the score to win, the time limit, how long the dead wait.
game.onStart, game.onTick, game.onReloadRun your code when the game starts, 60 times a second, and when the script is saved.
game.keep("saved", { best = 0 })Gives a table that keeps what you put in it when the script is saved and reloads; everything else in the file starts over. It holds numbers, text, true and false, players, and tables of those, until the game is closed.
game.onPlayerJoin, game.onPlayerLeave, game.onSpawn, game.onKillRun your code when something happens to a player.
game.onRoundStart, game.onRoundEndRun your code when a round starts and when it is won.
game.players(), game.teams(), game.team("Red")Who is in the match. A team has a name and a score, and team:addScore(1) changes it.
game.inputWhat the player is pressing, by action name ("jump", "fire", "move"), the same for keyboard, mouse and gamepad.
require("./weapons")Splits a game over files: runs weapons.luau, the file beside the one that asks, once, and gives back what that file ends with, such as return weapons. Paths start with ./ or ../ and stay inside the game's folder. Saving any of the files reloads the game.
game.input.rumbleShakes the gamepad of the player at this computer: game.input.rumble(0.2, 0.6, 0.1) is the heavy motor, the light motor, then seconds. On Linux and Windows, in fossps run; not on macOS yet.

The full list, with every setting and what each function is given, is fossps.d.luau. A copy is in every game's folder, which is what gives your editor autocomplete: in VS Code, install the Luau Language Server extension and open the game's folder.

Two games to read: hello, the smallest one, and team-deathmatch, with kill streaks kept in a second file.
