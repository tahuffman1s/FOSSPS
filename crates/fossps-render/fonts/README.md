# The engine's font

`AtkinsonHyperlegibleNext-Regular.ttf` is Atkinson Hyperlegible Next, by the Braille Institute of America: the font HUD and menu text is drawn in. It is built into the renderer unchanged.

- From: <https://github.com/googlefonts/atkinson-hyperlegible-next> (`fonts/ttf/AtkinsonHyperlegibleNext-Regular.ttf`), fetched 2026-11-15.
- SHA-256: `88ed5c31a71584c7772963b02d04bef1eb7e3d2e9c8b9cb204339b1f82cf432c`
- Licence: SIL Open Font License 1.1, in [`OFL.txt`](OFL.txt). No reserved font name is declared.

The licence lets the font be bundled and embedded in software under any licence, as long as its copyright notice and the licence travel with it and the font is not sold by itself. So `OFL.txt` goes into every release archive (`release.yml`) and every package `fossps package` writes.
